# 08 无铅钓组（Weightless / No Sinker，含 Wacky Rig 与 Neko Rig 挂法）

调研日期 2026-10-09；【核】＝只看到摘要（含 WebSearch 返回的摘要、B 站标题/简介），没读到原文，使用前应再核对。

本集分三种挂法：**A. 曲柄钩德州式无铅**；**B. Wacky（维基，横挂）**；**C. 尼科 Neko**（Wacky 横挂再在饵头插钉铅）。A、B 完全不加铅；C 其实插了铅，放在本集是因为挂法从 B 演变而来，和第 12 集「无铅插铅」的边界见第八节。

---

## 一、一句话结论

无铅钓组把软饵直接挂在钩上、不加外铅，靠高比重软饵（Senko 类棍虫）自身重量**慢慢、晃着往下沉**，解决的是「鲈鱼在浅水障碍旁、清水、高压、不追快饵」时饵太快、太吵的问题。高比重软饵无铅下沉时会左右摇摆，不需要钓手操作 [1]，大部分咬口发生在饵还没到底的下沉过程中 [10][12]。
- A 德州式无铅：钩尖藏进饵里，防挂，能扔进草、倒树、码头下；下沉是「慢的水平飘落」，官方说适合开阔水和悬浮的鱼 [1]，也有职业选手用它打浅水重障碍 [10]。
- B Wacky：钩从饵中段横穿，饵两头一起抖着下沉，动作最大、下沉最慢 [1][15]；钩尖外露，适合码头、倒树边和浅水稀疏障碍 [1][10]。
- C 尼科：饵头插钉铅，饵在底上「头朝下、尾翘起」立着抖 [1][5]，把 Wacky 的动作带到更深的底层，几乎一年四季、各种水深都能用 [3]。

## 三、挂饵与绑法分步

钓线和钩的结：本次**未查到**针对无铅钓组的专门结法出处；画面可用常见的帕洛马结或改良克林奇结，标注「常用结之一」即可。

### A. 曲柄钩德州式无铅（以 12.7 cm Senko + 3/0 EWG 为例）
1. 主线穿过钩眼，打结，剪线头。
2. 钩尖对准饵头端面正中，扎进去约 0.8–1 cm（大约等于钩柄前端那一段弯折的长度），从饵的腹侧穿出。（深度是按钩型画的建议值，未查到出处）
3. 把钩柄从穿出孔里往外拉，直到钩柄的弯折处（offset）卡进饵头，钩眼埋进饵头。
4. 把钩子转 180°，让钩尖朝向饵背。
5. 把钩子贴着饵身比一下，找到钩尖对应的位置，从腹侧把钩尖扎穿饵身，从背上出来。
6. 钩尖再轻轻挑回背上的表皮里，只埋进皮下（skin hook），饵身保持笔直、不弯 [14]【核】。不想挑皮的可以让钩尖露出、平贴在背上（Tex-pose）[14]【核】。

### B. Wacky（维基）
直接穿法：
1. 先找饵的重心：通常在中点，略偏饵头 [9]。可以把饵搭在手指上找平衡。
2. 钩尖从饵的一侧横着扎进中段，从另一侧穿出，钩柄和饵身成 90°，钩尖露在外面 [9]。
3. 抛前在水边试沉一次：哪头沉得快，就把钩往另一头挪一点再试 [9]。

O 圈套法：
1. 把 O 圈撑在 Wacky 工具（套管或撑圈钳）上，饵插进去一半，退下 O 圈，O 圈就落在饵的正中 [9]【核，此句来自 Wired2Fish 摘要】。
2. 把 O 圈滚到重心处 [9]。
3. 钩尖从 O 圈和饵身之间穿过去，**顺着饵身方向**（和饵平行），同时稍微带上一点饵的表皮，防止饵从 O 圈里滑出 [9]。
4. 钩尖朝外露出，开口不被软饵占住。

### C. 尼科 Neko
1. 把钉铅从饵头（较粗的一端）端面正中插进去，整根插入；想要触底感更清楚，可以留约 1–2 mm 露在外面 [5]【核】（「1–2 mm」是画面建议值，原文只说留一点）。
2. 套 O 圈（可选）：位置**偏向饵头**，大约离饵头三分之一处 [3][5]【核】。（不用 O 圈也行，Crews 认为直接穿更好，只有 Senko 这类很软的饵才用 O 圈 [2]）
3. 钩从 O 圈下面穿过（或直接横穿饵身），**钩尖朝饵尾方向、在饵的上侧** [3][5]【核】。理由：钉铅把饵头压到底下，饵是头朝下、尾朝上，钩尖朝尾就朝上，不容易挂底 [5]【核】。
4. 钩的位置不要偏离中段太多，拉线时饵要能「折」起来，才挂得住鱼 [2]。
5. 注意：John Crews 的原话是「about two-thirds up, away from the weighted head」（约三分之二处，远离加重的饵头）[2]，和第 2 步的「偏饵头」说法相反，见第九节。

## 四、水下动作分解

| 动作 | 饵怎么动 | 铅怎么动 | 咬口是什么感觉、什么时候扬竿 |
|---|---|---|---|
| 入水 | 无铅饵入水声小 [25]【核】 | A、B 无铅；C 钉铅在饵头，饵头先往下 | 入水后马上松线，别把饵拽走 |
| 自然下沉（A） | 饵身水平，慢慢飘落、左右小幅摇摆 [1] | 无 | 下沉时**放松线**，紧线会把饵往前拉、动作不自然 [11]【核】。盯线：线**突然一跳**或开始往别处走，就重扬竿 [11]【核】[12]【核】 |
| 自然下沉（B） | 饵中段挂钩，两头一起抖着往下落（「摇摆下沉」）[1]；Wacky 是无铅挂法里下沉最慢的 [15]【核】 | 无 | 同上；障碍下面的鲈鱼通常在下沉时就吃 [9] |
| 自然下沉（C） | 钉铅轻的时候，饵会打着转往下落，能引悬浮的鱼 [3] | 钉铅带着饵头先下 | 同上 |
| 停顿 | A、B：到底后不动几秒；C：饵在底上头朝下、尾翘起 [5]【核】 | C：钉铅贴底 | 停顿中线变松、线头慢慢横移，扬竿（经验说法，未查到专门出处） |
| 轻抽（A、B） | 抬竿尖让饵往前滑一段，再放低竿尖让它短距离「俯冲」下沉 [11]【核】 | 无 | 每次重新下沉都是咬口窗口 |
| 表层抽水 Twitch（B） | 让饵沉几秒，抽回到接近水面，再让它落 1–2 秒，重复到离开障碍区 [9] | 无 | 线跳、线走即扬竿 |
| 立底抖（C） | 线上保持「一点点张力」抖竿尖，饵立在底上抖；线一松饵就倒在底上不动了 [2]。动作越轻越好 [2] | 钉铅不离底 | 碰到木头不要误扬竿 [2]；可以拖、跳、抖 [3]，也可以松线死等（deadstick）配合竿尖轻抖 [4] |
| 中层横拉（C） | 对悬浮的鱼：数秒让饵沉到目标层，再用慢的竿尖抖动配合收线，让饵横着回来 [2] | 钉铅在前 | 感到重量或线停就扬竿 |

## 五、克重选择

A、B 不加铅，「克重」就是钩 + 软饵的自重。本次**未查到** Senko 单条克重的官方数据（零售商标的是整包重量，数字互相矛盾）。国内例子：12 cm T 尾约 9 g、4/0 弹簧钉曲柄钩约 2 g [24]【核】；11.3 cm 缓沉面条虫 3.6 g [29]【核】。

| 情况 | 建议 | 来源 |
|---|---|---|
| 水深约 1.5 m 以内，码头、倒树、草边 | A 或 B，完全不加铅 | [1][9] |
| 水深约 2.4–3 m，Wacky 下沉太慢 | 改用带配重的 Wacky（即 C 或铅头 Wacky） | [27]【核】 |
| C 常规（精细、底层） | 钉铅 0.9–3.5 g（1/32–1/8 oz），首选 1.8 g（1/16 oz） | [3][4] |
| C 障碍区 | 1.8–3.5 g（1/16–1/8 oz） | [4] |
| C 深水结构 | 3.5–5.3 g（1/8–3/16 oz） | [4] |
| C 选重原则 | 用能有效作钓的最轻钉铅，但要保持触底；太轻饵会漂、立不起来 [3]。Crews 的钉铅只用 1/16 oz（约 1.8 g）以下，更重就换蘑菇头配重 [2] | [2][3] |
| 有流水、风大 | 无铅饵会被流水和风带走（推断，未查到专门出处）；改 C 加重或换其它钓组 | — |

## 六、季节、天气、水温

### 鲈鱼（主写）
- 活性最高水温：约 18–28 ℃（推断，依据最适生长 25–30 ℃ [33]【核】和美国钓鱼站的 18–24 ℃ 偏好区间 [34]）。5 ℃ 以下、37 ℃ 以上不摄食 [32]。
- 春：水温升到约 15 ℃ 开始产卵 [32]。Wacky 在产卵前后到产卵后初期最好用 [9]，也可以对看得见的巢里的鱼投饵 [1]（注意：产卵期鲈鱼不摄食 [32]，守巢的鱼咬饵多是驱赶；当地有禁渔期的要遵守）。
- 夏：超过约 29 ℃ 有热应激 [34]，鱼进阴影、障碍下；无铅饵慢慢落进码头阴影、倒树下面正合适 [1][9]。
- 秋：水温回到 18–25 ℃（推断），A、B 打浅水障碍。
- 冬：B 站有「冬天最有效率的钓鲈钓组之一——无铅 T 尾钓组」的说法 [24]【核】，但没写水温和地区；国内资料也有「冬季低水温」用铅头 Wacky [28]【核】。水温低于约 12 ℃ 时更适合用 C 贴底慢抖（推断）。
- 天气与水色：德州式无铅在清水到微浑水最好，浑水效果差 [11]【核】；无铅钓组被国内 UP 主称为清水、高压、滑口鱼的「开口神器」[25]【核】。

### 鳜鱼（翘嘴鳜）
国内**没有**用无铅/Wacky/尼科钓鳜鱼的主流做法。B 站用「无铅钓组 鳜鱼」「无铅 鳜鱼 软饵」「neko 鳜鱼」检索，前 15 条里没有一条是无铅钓鳜鱼的教学 [30]。

### 翘嘴
国内**没有**主流做法。「无铅钓组 翘嘴」「无铅针尾 翘嘴」检索结果里没有无铅钓翘嘴的教学 [30]。

### 鱤鱼
国内**没有**主流做法。「鳡鱼 软饵 无铅」检索没有相关结果 [30]。

**尼科和无铅插铅的边界**（画面务必画清）：
- 两者都往饵里插了钉铅，名字都带「无铅」，新手容易以为「无铅」就是完全不加铅。
- 区分只看**钩怎么挂**：钩从饵中段**横着**穿（Wacky 式）＝尼科；钩从饵头**顺着**穿、钩尖藏进饵背（德州式）＝无铅插铅（第 12 集）。
- 国内 B 站也把尼科叫「插铅 Neko」[28]【核】，进一步加重混淆，口播里要点明。
- 尼科还要和「铅头 Wacky」（inch wacky，用铅头钩横挂面条虫）区分：铅头 Wacky 的铅在钩上，尼科的铅在饵里 [28]【核】。

## 九、误区与争议

1. **尼科钩尖朝饵尾还是饵头**
   - 朝饵尾（主流）：Wired2Fish 教程说钩尖朝饵尾、在上方，中钩率更高；钉铅让饵头朝下，钩尖朝尾就是朝上，不容易挂底 [5]【核】；Tackle Warehouse 也说钩尖朝向远离钉铅的一端、在上方，利于钩住上颚 [3]。
   - 朝饵头：有钓友一直朝饵头用了很多年 [7]；有人两种都试过「没发现中钩率有差别」[7]；Wired2Fish 做过水下对比视频，但有人说不是所有职业选手都同意它的结论（如 Iaconelli）[7]。视频本身的结论本次**未读到** [6]【核】。
   - 💬 评论区分歧点：尼科钩尖朝尾还是朝头？

2. **尼科钩挂在哪儿**
   - 偏饵头（约 1/3 处）：Tackle Warehouse「挂点要偏向插钉铅的『前端』」[3]；Wired2Fish「O 圈稍微偏向饵头，尾巴动作更大」[5]【核】。
   - 偏饵尾：Bassmaster 的 John Crews「约三分之二处，远离加重的饵头」，但同时说「还是要靠近中间，拉的时候饵能折起来」[2]。
   - 💬 评论区分歧点：尼科挂饵头 1/3 还是 2/3？

3. **O 圈还是直接穿**
   - O 圈：省饵，饵不撕烂 [1][9]；钩开口露得更多 [3]。
   - 直接穿：Crews 认为直接穿更好，只在 Senko 这种很软的饵上才用 O 圈 [2]。
   - O 圈法钩和饵平行，直穿法钩和饵垂直 [9]；有钓友说平行挂中钩率明显不如垂直，也有人说没差别（WebSearch 摘要转述的论坛帖，未取到原帖，不单列来源）。

4. **5 英寸 Senko 德州无铅用几号钩**
   - 3/0–4/0 EWG 是多数人的选择 [11]【核】[13]【核】；Bassmaster 选手 Jay Yelas 用 5/0 [10]。
   - 💬 评论区分歧点：12.7 cm 棍虫配 3/0 还是 5/0？

5. **Wacky 和德州无铅哪个钓得多**：有论坛帖转述 Gary Dobyns 说并排测试 Wacky 通常「10 比 1」赢德州挂法 [15]【核】；但 Yelas 认为重障碍里只能用德州挂法，Wacky 钩尖外露会挂 [10]。

6. **「无铅」到底插不插铅**：尼科插了钉铅，第 12 集无铅插铅也插了钉铅，都叫「无铅」。
   - 💬 评论区分歧点：插了钉铅的还算不算「无铅钓组」？

7. **误区：下沉时绷紧线**。紧线会把饵往前拉，破坏自然下沉 [11]【核】；尼科抖的时候反而要留一点张力，线全松饵就倒下 [2]。两种情况别搞反。
