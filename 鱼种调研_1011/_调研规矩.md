# 调研规矩（所有文件共用）

调研对象：路亚教学短视频（3D 动画，面向国内路亚新手）的鱼种系列事实调研。只做调研，不写口播稿。

## 通用规矩
- 地域默认长江中下游（江浙沪、太湖、长江干支流），北方、西南、华南的差异单独标注。
- 英文资料可以用，但美国的月份表和华氏温度不要搬。水温一律换成摄氏度，按国内实际水情说。
- 实验结论要点名具体鱼种，不外推到别的鱼；别的鱼的实验只能写「在 X 鱼上的实验」。
- 单位一律用厘米、米、克、千克（英寸、磅、盎司、英尺、华氏度全部换算）。
- 鲈鱼指中国大陆野化或放流的大口黑鲈（Micropterus salmoides），正文只叫「鲈鱼」；花鲈（海鲈、七星鲈，Lateolabrax maculatus）是另一种鱼，要分开写。
- 来源：抖音、淘宝打不开，不要去试。可以用：知网、万方等论文摘要，《中国动物志》等鱼类志和水产资料，农业农村部、各省渔政公告，知乎、钓鱼论坛、B 站文字简介和评论、英文论文和权威钓鱼站（FishBase、In-Fisherman、Bassmaster、Wired2Fish、Game & Fish 等）。
- 每个数字、每个结论都要落到来源表里，标注等级：A＝论文、志书或官方资料，B＝专业媒体或权威钓鱼站，C＝论坛或经验帖。只看到摘要（含 WebSearch 返回的摘要文字）、没读到原文的条目，标【核】。不要编造来源，查不到就写「未查到」。
- 不要创建 git 提交或 PR。

## 已知工具限制（前几轮调研的经验）
- WebSearch 只覆盖美国区索引，中文资料能搜到但偏少；知乎、Bassresource、Wired2Fish、禧玛诺官网等在 WebFetch 下常返回 403，只能看到搜索摘要，相关条目标【核】。
- 遇到 403/超时不要反复重试同一个 URL，换来源或标【核】。
- 不要编 URL。来源表里的 URL 必须是本轮或已有调研文件里真实出现过的。
