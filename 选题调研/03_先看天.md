# 题 3：到了水边先看天（事实调研）

> 地域默认长江中下游（江浙沪、太湖），其他地区单独标注。水温一律用摄氏度。
> 方括号里的编号对应文末「事实来源表」；标【核】的条目只看到搜索摘要或二手转述，没有逐字读到原文。
> **总体判断：** 天气对鱼的影响，**有研究支撑的很少**，大部分是钓鱼媒体和钓友经验。研究和经验几乎都以美国大口黑鲈为对象。鳜鱼、翘嘴、鱤鱼的天气行为**基本没有查到专门研究**，下面会逐条标明。

## 〇、先统一名词（片子里一定要先讲清楚）

国内钓友说「顺风岸、逆风岸、迎风岸」时，各人指的方向**经常相反**。本文统一这样用：
- **下风岸**：风**吹向**的那一侧岸。人站在这一侧，风迎面吹来，钓友常叫它「迎风岸」或「逆风岸」（因为是逆着风抛）。
- **上风岸**：风**吹离**的那一侧岸。人站在这一侧，风从背后吹，钓友常叫它「顺风岸」或「背风岸」。

> 动画提示：画一个俯视湖面，箭头表示风向，两侧岸分别标「下风岸（风吹过来）」「上风岸（风吹走）」，避开「顺、逆」这类有歧义的叫法。

## 一、风：下风岸还是上风岸

### 1. 常见说法：下风岸（风吹过来的岸）更值得钓
- **链条假说：** 风把浮游生物推向下风岸，小鱼跟着浮游生物走，掠食鱼跟着小鱼走 [T1]（B）【核】。专业钓手还说「风吹得越久，这条岸越好」[T1]【核】。
- **有研究支撑的部分：** 一项发表在《Limnology and Oceanography》的湖泊研究发现，持续的西风让下风端积累了更多**暖水**和**大型浮游动物**；小型浮游动物和叶绿素没有稳定的下风积累 [T2]（A）【核】。机制是：持续风把表层暖水推到下风端，使温跃层倾斜（所谓「传送带假说」）[T2]【核】。注意：这是**有分层的深湖**里的结果。
- **反对意见：** Bassmaster 系的文章认为，下风岸小鱼多「不是风把它们吹过去的，是它们在那里吃浮游生物」，健康的小鱼能自己游到任何地方 [T3]（B）【核】。也就是说，「风把小鱼吹过去」的说法不准确，准确的说法是「风改变了食物分布，小鱼主动跟过去」。
- **风浪的其他作用（经验）：**
  - 浪能把藏在泥和草里的虾、小动物冲出来 [T1]【核】。
  - 浪打碎水面，光线透不进去，鱼看不清岸上的人，更不怕人 [T1]【核】。
  - 风生表层流很慢：表层流速大约是风速的 2%，时速约 48 千米的风只产生约 0.8 千米 / 时的表层流（论坛引用的海洋学概数，未查到原始出处）[T4]（C）【核】。
- **有条件：** 论坛钓友指出，在饵鱼吃浮游生物的湖（例如有大量鲥类小鱼的美国水库），下风岸常常好；饵鱼不吃浮游生物的水体，背风的静水区反而可能更好 [T4]（C）【核】。

### 2. 太湖的特殊情况：夏季下风岸可能是「坏水」
- 太湖的实测研究显示，**风场是表层流场的主要驱动力**，不同湖区对风的响应不同，这是**蓝藻在不同湖区聚集程度不同**的主要原因之一 [T5]（A）【核】。
- 太湖局部水域出现过「**黑水团**」：**低溶解氧**、高氨氮、高硫化物。形成条件是蓝藻大量聚集、堆积、死亡，再加上**高温、风小、气压低、复氧能力弱** [T5]（A）【核】。
- **结论：** 在太湖，**夏季蓝藻季节**，被风吹到下风岸堆积的藻华可能耗氧、发臭，鱼反而会避开。「下风岸一定好」**不适用于太湖夏季藻华期**。其他季节、清水水域可以参考第 1 条的经验。

### 3. 溶氧和浑浊带
- **溶氧：** 风浪搅动水面，增加空气中的氧溶进水里，这是基本物理过程。资料提到锋面前的风浪「给水增氧、带来额外食物」[T6]（B）【核】。但**没有查到**「下风岸溶氧比上风岸高多少」的实测数据。
- **浑浊带：** 浪拍岸会把岸边泥沙搅起，形成一条浑水带。经验上掠食鱼会在**浑水与清水交界处**伏击 [T7]（B）【核】。没有查到针对四种鱼的研究。

### 4. 小结
| 结论 | 证据等级 |
|---|---|
| 持续风会把暖水和大型浮游动物推向下风端（有分层的湖） | A（单项研究）【核】 |
| 小鱼跟着食物到下风岸，掠食鱼跟着小鱼 | B / C 经验 |
| 风让鱼更不怕人 | B / C 经验 |
| 太湖夏季下风岸可能藻华堆积、缺氧 | A【核】 |
| 「下风岸比上风岸咬口率高」的定量研究 | **未查到** |

## 二、气压：降压、升压对鱼有什么影响

### 1. 有依据的部分（物理事实和少量实测）
- **气压变化很小，相当于水深变化几厘米：**
  - 每下潜约 10 米，水压增加约 1 个大气压 [T8]（B）【核】。
  - 一次普通冷锋过境，气压变化约 0.06 个大气压 [T8]【核】。
  - 按此计算：0.06 个大气压约相当于 **60 厘米水深**的压力变化。一天内的日常气压波动更小，相当于**几厘米到十几厘米**水深。鱼在水里上下游动一下，承受的压力变化就比这大得多 [T8][T9]（B）【核】。
  - In-Fisherman 文章原话：鱼换个深度，上下几十厘米（原文一两英尺），造成的压力变化「与大多数自然气压变化一样大或更大」[T9]（B）。
- **鱼鳔确实能感受压力变化，但没有证据表明鱼能分辨天气气压：**
  - 研究综述认为，鱼可以通过鱼鳔体积的变化，感知静水压力变化的大小和方向，用来判断自己在什么深度 [T10]（A）【核】。
  - 鲤科鱼（**翘嘴、鱤鱼都属于鲤科**）有「韦伯氏器」，把鱼鳔和内耳连起来。金鱼（鲤科）实验显示这类鱼对**声压**特别敏感 [T10]【核】。但这是**声音**的压力，不是天气气压的缓慢变化。
  - In-Fisherman 文章指出：鲈鱼用鱼鳔调节浮力，气压或深度一变，鱼会重新调节鱼鳔，所以小幅气压变化**不太可能被持续感知**；**生物学家还没有找到**鱼能探测天气气压变化的物理机制 [T9]（B）。
- **唯一查到的实测（鲈鱼，小样本）：**
  - 美国德州 Travis 湖，Ralph Manns 用电子追踪加潜水观察，记录了 100 多个变量，其中包括气压 [T9]（B）。
  - 低气压时 52% 的鲈鱼咬饵，高气压时 39% [T9]。
  - 气压**缓慢下降**时 65% 的鲈鱼咬饵，**缓慢上升**时只有 30% [T9]。
  - 但作者自己说：样本**很小**；高低气压本身**不能稳定地说明**鲈鱼的活性；结果可能混入了月相等因素，「不一定说明降压就能提高钓获」[T9]。
  - 在更大的追踪样本里：缓慢升压时 29% 的鲈鱼在离岸处觅食，缓慢降压和气压稳定时都是 24%，**和钓获数据的方向相反** [T9]。

### 2. 只是民间说法、没有可靠证据的部分
| 说法 | 情况 |
|---|---|
| 「降压时鱼鳔胀、鱼难受，所以不吃」 | 没有找到实验证据；气压变化量相当于几厘米到几十厘米水深，鱼日常上下游动就超过这个量 [T8][T9] |
| 「降压时鱼觉得肚子空，所以抢食」 | 论坛说法 [T6]（C），没有证据 |
| 「29.5–29.8 英寸汞柱是钓鲈鱼最佳气压」 | 网页引用的「研究」查不到出处 [T11]（C） |
| 「降压能把钓获率提高 25%」之类的百分比 | 网页没给期刊、日期，无法核实 [T11]（C） |
| 「高压天鱼不开口」 | Manns 的数据显示高低气压本身不能稳定预测活性 [T9] |

### 3. 比较靠谱的理解
- 多个来源倾向于认为：**气压是天气变化的「指示器」，不是鱼行为的直接开关** [T11]（B / C）【核】。降压往往意味着锋面要来：起风、云量增加、光线变暗、气温变化，这些才可能是影响鱼的直接原因。
- 新手可以这样理解：**看气压，是为了预判天气要变，不是因为鱼能「感觉到气压」**。

## 三、降温和升温：冷锋过境前后

> 本节资料主要是**鲈鱼（大口黑鲈）**，与题 2 第四节一致，这里只列要点。

| 阶段 | 天气特征 | 鲈鱼表现 | 依据 |
|---|---|---|---|
| 冷锋来前 | 南风或偏暖、多云、降压、起风 | 经验上常抢食；风浪带来食物和氧 | [T6]（B / C）【核】 |
| 冷锋过境当天到次日 | 转北风、降温、天空变得很蓝、升压 | 进食**显著减少**，还在吃的多是小个体 | 内布拉斯加大学林肯分校学生论文 [T12]（A）【核】 |
| 过境后 1–2 天 | 晴冷 | 有时第二天最难；鲈鱼缩回遮蔽物、垂直结构 | Bassmaster [T13]（B）【核】 |
| 回暖 | 气温回升 | 约 3 天后恢复温和进食（经验值） | [T6]（C）【核】 |
| 例外 | — | 冷锋不一定关掉咬口 | In-Fisherman [T14]（B）【核】 |

**升温：**
- 冬末到春季，连续几天升温比单日的绝对温度更重要。这是钓友的普遍说法，有中文经验帖称「升温过程比稳定温度更重要」[T15]（C）【核】。本次**未查到研究支撑**。
- **夏季高温：** 鳜鱼在 32 °C 以上食欲减退 [T16]（C）。高温天降温（例如一场雨）对鱼往往是好事，属于经验。

**其他鱼：** 鳜鱼、翘嘴、鱤鱼的冷锋前后行为**未查到专门资料**，不外推。

## 四、下雨：雨前、雨中、雨后，浑水和进水口

| 阶段 | 资料说法 | 依据与等级 |
|---|---|---|
| **雨前** | 雨前往往伴随降压、起风、云层变厚、光线变暗，因此「雨前好钓」的经验，和第一、二、五节说的风、光线变化是同一回事 | 推断；单独针对「雨前」的研究**未查到** |
| **雨中（小到中雨）** | 美国资料普遍认为小到中雨、持续几小时、没有大风雷电最理想；雨点打碎水面，鱼更不怕人 | 一般钓鱼网站（C）【核】[T17] |
| **雨中（雷雨）** | **立即收竿**。碳素竿导电，雷雨天站在开阔水边很危险（安全内容见题 1 第六节） | 题 1 [S22][S23] |
| **雨后：进水口** | 地表径流把虫、虾等食物冲进水体，小鱼被吸引过来，鲈鱼跟着来；暴雨后从**排水口、溪流入口、护坡石岸、新淹没的岸边障碍**开始找 | BassResource / Tackle Village / Kayak Guru [T7]（B / C）【核】 |
| **雨后：浑清交界线** | 鲈鱼会沿着「泥线」（浑水和清水的交界）伏击；泥线**多是雨后第一天的现象**，随后水体混合、水位回落就消失了 | [T7]【核】 |
| **雨后：太浑** | 有职业钓手说「在大浑水里钓，钓不到多少鱼」，建议去支流上游、湾子深处找**先变清的水** | [T7]（B）【核】 |
| **浑水选饵** | 用有**振动、大轮廓、带气味**的饵：复合亮片、Chatterbait、方嘴 crank、铅头钩软饵加气味 | ODU Magazine / BassResource [T7][T18]（B）【核】 |
| **浑水颜色** | 资料里**没有可靠的颜色建议**；「浑水用亮色、黑色剪影」是常见经验，未查到研究 | — |
| **水位上涨** | 河流水位上涨，鱼会进入新淹没的区域 | 一般钓鱼网站（C）【核】[T17] |

## 五、晴天和阴天：光照、鱼的位置、离掩体的距离

### 1. 「晴天鱼贴紧掩体、阴天鱼出来游」：有反证
- **反证（追踪研究）：** Outdoor Life 报道的 Lembeck 遥测研究追踪了单条鲈鱼，结论是鲈鱼**对日光没有偏好**：不专门选掩体的阴影一侧，正午也不会为了找阴影而下沉；无论雨天、阴天、晴天，都守在自己喜欢的位置 [T20]（B）【核】。这不是同行评审研究。
- **支持（有条件）：**
  - **浑水**里，晴天鲈鱼留在浅水，但**紧贴**大石缝、树枝堆这类掩体 [T21]（C）【核】。
  - **清水湖**里，晴天鲈鱼反而移到较深处，悬浮在坎边、岬角或立木附近 [T21]【核】。
  - 阴天能见度下降，鲈鱼觉得更安全，**游离掩体更远** [T21]（C）【核】。
- **实验室研究：** 蒙大拿州立大学测过大口黑鲈在从夜间到白天不同光照下的捕食成功率 [T22]（A）【核】。本次没读到全文，**不能确定**它关于位置的结论，只记录为「光照影响捕食成功率」这一方向。

### 2. 本文的整理
- 对鲈鱼来说，**水的清浊比晴阴更重要**：清水加晴天，鱼会往深处走、更怕人；浑水加晴天，鱼留在浅处、贴紧掩体。阴天普遍认为鱼更敢出来游，但有追踪研究不支持这个规律 [T20][T21]。
- **鳜鱼：** 「胆小，怕光怕惊，白天卧穴，一般在夜晚摄食」[T16]（C）。所以**弱光**（清晨、傍晚、阴天）对鳜鱼更有利，这是从生活习性推的，**没有查到「阴天咬口率」的实测**。
- **翘嘴：** 经验上翘嘴在弱光时段上浮到水面追饵（早晚的「起水」），白天多在中下层 [T23]（C）【核】。晴阴的影响**未查到研究**。
- **鱤鱼：** **未查到**。

## 六、按四种鱼总结：哪种天气最值得出门，哪种天气该换打法

> 「证据」一列说明这一格的依据强度；「未查到」的地方就是没有资料，不要在片里说成定论。

| 鱼 | 最值得出门 | 最该换打法 | 证据 |
|---|---|---|---|
| **鲈鱼** | 冷锋**来之前**；有持续风的下风岸（太湖夏季藻华期除外）；雨后第一天的进水口和泥线；阴天或小雨 | **冷锋过后 1–2 天**：换慢、小、贴遮蔽物和垂直结构的打法；**大浑水**：换振动强、轮廓大的饵，或者去找先变清的水；**清水大晴天**：往深处找 | B 级为主，一项小样本实测 [T9]、一项学生论文 [T12] |
| **鳜鱼** | 弱光时段（清晨、傍晚、阴天）；流水、清水、有石头的地方 | 晴天正午：鳜鱼卧穴，打法要贴底、慢、往石缝桥墩根部送；大浑水：效果**未查到**，经验上不推荐 | 生活习性资料（C）[T16][T19]；天气与咬口的关系**未查到研究** |
| **翘嘴** | 经验上：早晚弱光、阴天、有风浪的开阔水面（翘嘴追饵鱼） | 经验上：晴天正午换到中下层，用 VIB、铁板之类能沉下去的饵 | 全部是 C 级经验 [T23]；**未查到研究** |
| **鱤鱼** | **未查到** | **未查到** | 无；长江干流禁捕，本题建议不讲 |

**给新手的一句话版本（按证据强度排序）：**
1. **冷锋过后要换打法**：这一条有学生论文加多个专业来源支持，最可靠（鲈鱼）。
2. **风会改变食物分布**：有一项湖泊研究支持，但「下风岸咬口更好」没有定量证据，太湖夏季要小心藻华。
3. **气压是天气的「预报员」，不是鱼的「开关」**：气压对鱼的直接作用没有科学证据。

## 误区与争议

1. **🔥【评论区可抛】「顺风岸好还是逆风岸好？」**
   这个问题一半是**名词之争**：有人说的「顺风岸」是风吹过去的岸，有人说的是背后来风的岸。先统一成「下风岸、上风岸」再讨论（见第〇节）。真正的结论是：下风岸**常常**更好，有一项湖泊研究支持浮游动物在下风端积累 [T2]，但有专业文章反对「风把小鱼吹过去」[T3]，太湖夏季下风岸可能藻华堆积缺氧 [T5]。很适合在评论区抛。
2. **🔥【评论区可抛】「鱼鳔能感受气压，所以降压不开口」**
   一次冷锋的气压变化只相当于水深变化几十厘米，日常波动相当于几厘米 [T8][T9]；鱼上下游动一下的压力变化都比这大。生物学家还没找到鱼能感知天气气压的机制 [T9]。鱼鳔能感受**水深**变化有研究支持 [T10]，但**不能推到天气气压**。这条最适合拿来做「科普反转」。
3. **🔥【评论区可抛】「降压抢口，升压停口」**
   唯一的实测是小样本：缓慢降压时 65% 咬饵、缓慢升压时 30%，但更大的追踪样本方向相反，作者自己也说不能下结论 [T9]。民间经验和数据打架。
4. **「晴天鱼都躲在阴影里」，有反证。** 有追踪研究说鲈鱼不挑阴影、不随日照换位置 [T20]；水的清浊可能比晴阴更重要 [T21]。
5. **「下雨一定好钓」，部分正确。** 小到中雨通常被认为不错；雷雨危险必须收竿；大浑水不一定好，要找浑清交界或先变清的水 [T7][T17]。
6. **「天气规律对所有鱼都一样」是误区。** 几乎所有资料都来自美国大口黑鲈；鳜鱼怕光、夜间摄食 [T16]，翘嘴追饵鱼群，生活方式差别很大，不能互相套用。
7. **资料局限：** 「29.5–29.8 英寸汞柱最佳」「降压提高 25% 渔获」这类精确数字都**查不到出处** [T11]，片中不要用。
